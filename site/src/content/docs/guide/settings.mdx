サイドバーの **設定** タブから変更できます。設定は自動保存され、再起動後も保持されます。

## 共通

### Discord Rich Presence を有効にする

- ON にすると、検出したメディア情報を Discord へ送信します (既定: ON)
- OFF の間もメディアの検出自体は継続し、アプリ内のダッシュボードには表示されます
- Discord へ送られるデータの詳細は [しくみ](../how-it-works/#discord-に送られるデータ) を参照

## デスクトップ版のみ

### 自動起動

Windows ログイン時にアプリを自動で起動します。設定変更はすぐに OS へ反映されます。

### トレイで起動

起動直後にウィンドウを開かず、タスクトレイ常駐のみで開始します。

### 最小化時にトレイへ格納

最小化ボタンでウィンドウを閉じず、タスクトレイへ格納します。

### 閉じる時にトレイへ格納

閉じるボタン (×) でもアプリを終了させず、タスクトレイへ格納します。完全に終了するにはトレイメニューから **終了** を選択してください。

:::note[タスクトレイ]
トレイアイコンの左クリックでウィンドウを表示できます。右クリックのメニューからは **開く / 設定を表示 / 終了** が実行できます。
:::

### 更新 (タブ)

デスクトップ版ではサイドバーに **更新** タブがあり、以下が行えます。

- 手動でのアップデート確認
- ダウンロード進捗の表示と、完了後の「インストールして再起動」
- リポジトリ・変更履歴へのリンク

また、起動時に新しいバージョンがある場合は OS 通知でお知らせします。アップデーターの配信元は GitHub Pages (`update.json`) です。

## Android 版のみ

### 常駐通知

ON にするとフォアグラウンドサービスとして常駐し、「再生中の曲名」を内容とした常駐通知を表示します (既定: ON)。

- プロセスの生存が保証され、長時間の再生でも検出が途切れにくくなります
- 通知上のボタンで **Discord RPC の ON/OFF** を直接切り替えられます
- 一部端末 (HyperOS など) では通知アクセス設定画面の挙動が特殊なため、アプリ側から案内する場合があります
- OFF にしてもメディア検出は動作しますが、OS の省電力機能により検出が停止する可能性があります

### ホワイトリスト

メディアの検出対象とするアプリを選択します。

- インストール済みアプリを名前で検索して追加できます
- **ホワイトリストが空の場合、どのアプリも検出されません**
- 追加できるのはメディア再生を行うアプリです (表示名とパッケージ名で管理)

## ライセンス / バージョン (タブ)

- **ライセンス**: アプリが利用しているサードパーティライブラリーの一覧とライセンス文を表示します
- **バージョン**: アプリのバージョン情報を表示します。Android 版では APK 署名証明書の SHA-256 フィンガープリントも表示され、配布された APK が正規のものであるか ([Releases](https://github.com/hu-ja-ja/WSA_RPC_Bridge/releases/latest) 添付の `apk-signing-fingerprint.txt` と照合) を確認できます

## 設定ファイルの保存場所

| プラットフォーム | 場所 |
|---|---|
| Windows | `%APPDATA%\wsa-rpc-bridge\config.json` |
| Android | アプリ内部ストレージ (SharedPreferences) |

Windows 版のローカルデータ (APK 名解決キャッシュなど) は `%LOCALAPPDATA%\wsa-rpc-bridge\` に保存されます。アンインストールしても自動削除されないため、手動で削除してください。詳しくは [プライバシーポリシー](../../legal/privacy/) を参照してください。
