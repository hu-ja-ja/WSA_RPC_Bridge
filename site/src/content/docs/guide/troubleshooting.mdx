症状から探して対処してください。解決しない場合は [GitHub Issues](https://github.com/hu-ja-ja/WSA_RPC_Bridge/issues) までお知らせください。

## Android 版

### アプリの UI が真っ白で何も表示されない

Android システムの WebView が古いと、UI の描画に必要な JavaScript 機能 (ES Module など) が動作しません。

- Play ストアから **Android System WebView** を最新に更新してください
- 更新後、端末を再起動すると改善する場合があります

### 再生しているのに Discord に表示されない

以下を順に確認してください。

1. **通知アクセス権限**が許可されているか — 設定タブ上部のバナーまたは `設定 > アプリ > 特別なアクセス > 通知へのアクセス` から許可できます
2. **ホワイトリスト**にその音楽アプリが登録されているか — ホワイトリストが空の場合は何も検出されません
3. **Discord RPC が有効か** — 常駐通知上のボタンやダッシュボードのトグルを確認してください
4. 端末上の **Discord アプリが起動済み**か
5. 長時間再生していなかった場合は [アイドル時の自動切断](../how-it-works/#android-版) が働いています。RPC を OFF→ON するか、アプリを再起動してください

### しばらく操作すると検出が止まる

OS の省電力機能によりバックグラウンド処理が停止した可能性があります。設定で **常駐通知** を ON にすると、フォアグラウンドサービスとして動作し安定します。

### 通知アクセスの設定画面で切り替えられない (HyperOS 等)

一部メーカー環境では設定画面の挙動が特殊なため、アプリ内の案内に従ってシステム設定画面から直接許可してください。

## デスクトップ版 (WSA)

### 再生しているのに検出されない

1. WSA 側で **開発者モード** が有効になっているか確認してください。ADB 接続は開発者モードに依存します
2. Windows ネイティブのアプリ (PC ブラウザ・デスクトップ音楽アプリ) での再生は **対象外** です。WSA 内のアプリで再生してください
3. ダッシュボードの ADB 状態表示がオフの場合、WSA が起動していない可能性があります

### Discord に反映されない

1. ログイン済みの **Discord クライアント** が起動しているか
2. ダッシュボードの **RPC トグル** が有効か
3. 検出内容に変化があると更新されます (同一楽曲のループ再生など変化がない場合は更新されません)

## 共通

### 表示が数秒遅れる

デスクトップ版は 5 秒間隔でのポーリングにより検出するため、最大数秒の遅延があります。Android 版はイベント駆動のため即時に反映されます。

### アンインストールしてもデータが残る (Windows)

`%APPDATA%\wsa-rpc-bridge\` (設定) と `%LOCALAPPDATA%\wsa-rpc-bridge\` (キャッシュ) は自動削除されません。不要な場合は手動で削除してください。
