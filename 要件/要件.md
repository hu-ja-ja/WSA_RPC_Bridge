# 目的

WSA上で動作しているAndroidアプリケーションの情報をADB経由で取得し、Discordのアクティビティステータス(Ritch Presence)に表示することを目的とする。
第一段階では、音楽再生アプリをメインターゲットとし、再生中の曲のタイトルやアーティスト名、再生時間などを表示することを目標とする。

## 概要

開発言語は主にRustを使用し、Windows上で動作するGUIアプリケーションとして開発する。

### 使用予定ライブラリ

- Discord Social SDK (C++)

### ADBの使用

WSAでは、公式にADBコマンドがサポートされており、Windows上でADBを使用してWSA上のAndroidアプリケーションと通信することが可能である。

コマンド例:

```pwsh
adb exec-out dumpsys media_session
```
