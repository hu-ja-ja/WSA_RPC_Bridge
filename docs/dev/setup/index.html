環境構築

必要なツール

Section titled “必要なツール”

ツールは mise で管理しています。

ツール バージョン 用途
Node.js 22 フロントエンド / ドキュメントのビルド
pnpm 11.x JS 依存の管理
Rust 1.97 Tauri バックエンド
Java 21 Android ビルド
Perl - ビルドスクリプト

セットアップ

Section titled “セットアップ”

mise 本体が未導入の場合は mise の導入手順 に従ってください。その後、clone から依存導入までを通します。

開発サーバーの起動

Section titled “開発サーバーの起動”

起動時、build.beforeDevCommand (pnpm generate-licenses && pnpm dev) が先に実行され、ライセンス生成 → Vite dev server (http://localhost:5173) が立ち上がります。

デスクトップ

Section titled “デスクトップ”

成果物は src-tauri/target/release/bundle/msi/ に出力されます。軽く通すだけなら pnpm tauri build --no-bundle でも確認できます。Infisical 未ログイン時は pnpm tauri ... を直接実行してください (詳細は コマンドリファレンス)。

Android

Section titled “Android”

Android SDK / NDK は mise.toml の SDK_ROOT / NDK_VERSION から解決されます。未導入の場合は Android Studio または cmdline-tools (sdkmanager --licenses 後に NDK を導入) で用意してください。

  • gen/android 本体は git 管理済みのため、android init は不要です。fresh checkout で不足する生成物 (generated/ Kotlin・tauri.*.gradle*・libs/rustls-platform-verifier.aar) は pipeline:codegen が補います (詳細は Pipeline)。
  • 規約上リポジトリに置けない discord_partner_sdk.aar が無くても dev ビルドは通ります (任意依存 + リフレクション呼び出しのため)。リリース時の取得は リリース を参照してください。
  • gradle が応答しなくなった場合は src-tauri/gen/android で gradlew.bat を直接実行してください。

よく使うコマンド

目的 コマンド
