プライバシーポリシー

プライバシーポリシー

Section titled “プライバシーポリシー”

制定日: 2026年8月5日 改定日: 2026年8月19日

1. はじめに

Section titled “1. はじめに”

WSA RPC Bridge (以下「本アプリ」) は、WSA (Windows Subsystem for Android) 上で動作しているアプリケーションのメディア再生情報を取得し、Discord Rich Presence に表示するアプリです。

本アプリには以下の 2 つの形態があります。

  • Windows 版: Windows PC 上で動作するデスクトップアプリ。WSA のメディア再生情報を ADB 経由で取得します。
  • Android 版: Android 端末上で動作するアプリ。端末内で直接メディア再生情報を取得します。

本ポリシーでは、本アプリが取り扱うデータとその送信先について説明します。

本アプリのご利用にあたっては、利用規約 も併せてご確認ください。

2. 個人情報の収集について

Section titled “2. 個人情報の収集について”

本アプリは、開発者側に個人情報を収集・送信することはありません。以下の機能は一切実装されていません。

  • テレメトリ / アクセス解析
  • 広告
  • アカウント作成・ログイン
  • クラッシュレポートの自動送信
  • ログの外部送信

3. コア機能

Section titled “3. コア機能”

本アプリの動作に不可欠な機能です。

メディア再生情報の取得 (Windows 版)

Section titled “メディア再生情報の取得 (Windows 版)”

本アプリは WSA 上のメディア再生情報を取得するために ADB を使用します。ADB 通信はローカル (同一 PC 上の WSA との通信) のみであり、外部サーバーへデータが送信されることはありません。

メディア再生情報の取得 (Android 版)

Section titled “メディア再生情報の取得 (Android 版)”

本アプリは、端末の通知アクセス権限を利用し、Android の MediaSession から現在のメディア再生情報を端末内で直接取得します。取得は端末内で完結しており、外部サーバーへデータが送信されることはありません。

対象となるアプリは、設定でホワイトリストに追加したアプリのみ検出されます。

常駐通知 (Android 版・任意)

Section titled “常駐通知 (Android 版・任意)”

本アプリは、設定で「常駐通知」を有効にした場合に限り、フォアグラウンドサービスとして常駐し、再生中のメディア情報 (タイトル・アーティスト・アルバム・再生状態) を端末の通知として表示します。この機能は任意であり、設定で無効にできます。これは端末内のみの表示であり、通知の内容が外部へ送信されることはありません。

アクセス権限 (Android 版)

Section titled “アクセス権限 (Android 版)”

本アプリは、以下の権限を要求します。

権限 種別 利用目的
通知へのアクセス 特別なアクセス権限 (設定で手動許可) メディア再生情報の取得のため、Android の MediaSession を検出する
通知の表示 (Android 13 以降) ランタイム権限 常駐通知を表示する
フォアグラウンドサービスの実行 通常権限 メディア再生情報の収集を継続するため、サービスを常駐させる
インターネット 通常権限 Discord への送信、サムネイル解決の通信を行う

通知へのアクセス権限は他のアプリの通知を参照できる権限ですが、本アプリはこの権限をメディアセッションの検出にのみ使用し、他のアプリの通知内容を読み取る機能は実装していません。通知内容の閲覧・保存・送信・その他いかなる用途にも使用されることはありません。このことは、ソースコード上でも確認することができます。

Discord Rich Presence (共通)

Section titled “Discord Rich Presence (共通)”

本アプリの主要機能です。設定で Discord Rich Presence を有効にしている場合のみ、再生中のメディア情報が Discord に送信され、Discord のアクティビティとして表示されます。

  • Windows 版では Discord クライアント経由で送信されます。
  • Android 版では端末上の Discord アプリに直接接続して送信されます。

送信されるデータ:

  • メディアタイトル (曲名・動画タイトル)
  • アーティスト名
  • 再生中のアプリ名
  • サムネイル画像の URL
  • 再生位置・再生時間

表示内容は Discord の設定に従って他ユーザー (フレンド等) からも見える場合があります。また、Discord 側のデータの取り扱いについては Discord のプライバシーポリシー を参照してください。

4. オプションのサードパーティ連携機能

Section titled “4. オプションのサードパーティ連携機能”

本アプリは、特定のアプリとの連携機能をプラグイン構造 (ArtworkResolver) で提供しています。これらの機能は対応するアプリが再生されているときのみ動作し、そのときのみ外部サーバーへのデータ送信が行われます。 この連携機能は Windows 版・Android 版の両方で動作します。

連携先アプリ 目的 送信されるデータ 送信先 送信タイミング
ボカコレ (jp.nicovideo.nicobox) サムネイル画像の取得 メディアタイトル (曲名・動画タイトル) ニコニコ検索 API (snapshot.search.nicovideo.jp) 再生中のみ

取得したサムネイルは画像ファイルとして保存されず、URL のみがアプリ内のメモリ上に一時保持され、Discord Rich Presence に送信されます。画像本体は本アプリでは取得・保存せず、Discord 側で取得・表示されます。

将来の連携追加について

Section titled “将来の連携追加について”

上記のプラグイン構造により、今後新しいサードパーティ連携が追加される可能性があります。連携が追加された場合、本ポリシーに追記し、常に「対応する機能を使用しているときのみ送信される」という原則を維持します。

5. ローカルデータの保持と削除

Section titled “5. ローカルデータの保持と削除”

本アプリは以下のデータをローカルのみに保存します。

プラットフォーム データ 場所 内容
Windows 版 設定ファイル %APPDATA%\wsa-rpc-bridge\config.json アプリの設定 (自動起動、キャッシュ設定など)
Windows 版 APK キャッシュ %LOCALAPPDATA%\wsa-rpc-bridge\ApkCache アプリ名解決用の一時ファイル
Android 版 設定・ホワイトリスト アプリ内部ストレージ (SharedPreferences) アプリの設定、メディア検出対象のホワイトリスト

Windows 版のデータはアプリをアンインストールしても自動的には削除されません。削除する場合は、上記の wsa-rpc-bridge フォルダを手動で削除してください。

Android 版のデータはアプリをアンインストールすると端末から削除されます。
